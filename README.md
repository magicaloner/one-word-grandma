Exactly one word and nothing else: the single word their grandma would text about AI. A real word, a family in-joke, a typo she would actually make or text-speak all count, as long as it is one word.

## The word

> Robit

Grandma's typo of "robot" — the word she would actually text, misspelled with total confidence.

## Run it

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
